# Organograma — os 56 cargos de uma emissora

Cruzamento função por função do organograma de um estúdio de TV com os robôs
do estúdio. Versão visual publicada como artifact em 18/08/2026.

| | |
|---|---|
| **Cobertas** | 36 — têm dono entre os robôs |
| **Construídas nesta rodada** | 19 — não tinham dono antes |
| **Parciais** | 5 — cobertas em parte, com limite declarado |
| **Sem equivalente** | 15 — só existem com estúdio físico |

"Sem equivalente" significa que a função depende de captação de imagem,
iluminação de set, transmissão por rádio ou figurino real — não que foi
esquecida.

## As cinco coberturas parciais

**Direção de fotografia.** O tratamento de imagem hoje é uma escurecida leve
para a legenda ter contraste, mais a moldura do GC. Não existe um *look*
deliberado — curva de cor, temperatura, granulação — que faça o vídeo parecer
sempre do mesmo programa. É decisão estética, não obstáculo técnico: os filtros
já estão no lugar.

**Figurino, maquiagem e cabelo.** O apresentador é uma imagem fixa em duas
versões. Não muda de roupa, não tem versão de feriado nem de luto. Aceitável no
começo, vira limitação quando o público já conhece o personagem. A saída é ter
jogos de imagem por ocasião — o sistema já troca por arquivo.

**Playout.** A publicação continua sua, por decisão de projeto. A API do TikTok
é gratuita mas exige auditoria de 1 a 2 semanas e, até sair, só publica vídeo
visível apenas para o autor.
